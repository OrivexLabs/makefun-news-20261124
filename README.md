A pure-stdlib Python program that turns 24 November 2026's world news into one deterministic 1024x1024 newspaper-style image: the COP31 collapse in Antalya as the lead, Ukraine's strike on a Russian corvette in Benghazi, the UNRWA worker killed in Gaza, Jensen Huang's return at Nvidia, Armenia's draft constitution, and five briefs. Every item was checked against at least two independent sources. No third-party packages: text is drawn from embedded pre-rendered glyph bitmaps, and two runs produce a byte-identical PNG.

## Run it

```sh
python3 main.py
```
